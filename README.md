## What it does


Writing commit messages is the most procrastinated 30 seconds in a developer's day. SlothCommit removes it:


1. Run `git diff --staged` in your terminal
2. Paste the diff into SlothCommit
3. Get back a proper commit message (Conventional Commits / Simple / Emoji style) + an optional PR description
4. Copy, paste, done. Back to napping.


## How it's built


- **Frontend**: Single zero-build `index.html` — no framework, no bundler
- **Backend**: Cloudflare Pages Function (`functions/api/generate.js`)
- **AI**: [Llama 3.1 8B Instruct](https://ai.meta.com/llama/) (open weights) via [Cloudflare Workers AI](https://developers.cloudflare.com/workers-ai/) — no API keys, no per-token billing
- **Domain**: Deployed on `commit.tianx.tech` (a `.tech` domain)


## Why open weights?


Your diffs contain your uncommitted work — half-baked ideas, internal APIs, proprietary logic. Sending that to a closed API means trusting a third party with your unfinished code.


With open-weight Llama running on Cloudflare's edge:
- **No data hoarding**: your diff is processed and forgotten, not logged for training
- **No subscription**: Workers AI free tier covers this workload; set it up once, never pay
- **Works for everyone**: anyone can fork this repo and deploy their own copy in minutes


## Run it yourself


**Option A — local (full AI, recommended for the demo):**
```bash
git clone https://github.com/joemh79/sloth-commit.git
cd sloth-commit
ollama pull gemma3:4b   # open-weight model, runs on your machine
python3 local_server.py  # opens http://localhost:8080
```


**Option B — Cloudflare Pages:**
```bash
# 1. Create a Pages project, upload this folder
# 2. Settings → Functions → Add binding: AI → Workers AI
# Note: the live demo at commit.tianx.tech currently serves the UI;
# full AI generation runs locally via Ollama (Option A).
```
